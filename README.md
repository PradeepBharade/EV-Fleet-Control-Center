# Autonomous EV Fleet Control Center

A real-time web-based control platform for monitoring and managing an autonomous EV fleet.

## Features

- Real-time fleet monitoring and vehicle telemetry
- Vehicle health dashboard
- Ride queue and assignment
- Incident logging
- Interactive fleet map
- Simulated multi-camera feeds
- Remote vehicle takeover
- Automated cleaning dispatch

## Tech Stack

- React.js
- JavaScript
- Node.js
- Express.js
- WebSockets
- HTML
- CSS
- Git & GitHub

## Project Overview

This project simulates a control center used to monitor and manage autonomous electric vehicles. The dashboard provides fleet operators with real-time vehicle information, location tracking, vehicle health data and operational controls.

WebSockets are used to provide real-time communication between the frontend and backend for vehicle telemetry and control events.
